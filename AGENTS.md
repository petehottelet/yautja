# Private project documents

Keep all private planning documents, draft PRDs, implementation plans, handoffs, and working notes in `00_project_files/`. That directory is ignored by Git and excluded from release packages.

Never commit, push, or publish private planning files to GitHub or include them in package or skill distributions. Do not force-add ignored planning files. Review staged paths before committing. User-facing documentation such as the README, API guide, changelog, and public roadmap belongs in the repository.
