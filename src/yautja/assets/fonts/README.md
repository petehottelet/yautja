## Orbitron

Unmodified static Light, Medium and Bold TTFs by Matt McInerney from
[The League of Moveable Type](https://github.com/theleagueof/orbitron/tree/13e6a5222aa6818d81c9acd27edd701a2d744152).
The bundled `Orbitron-OFL.txt` preserves the upstream copyright and SIL OFL 1.1 license.
Only filenames replace spaces with hyphens; font bytes and internal names are unchanged.
`--hud-font orbitron` selects the original Light face; the other choices name their weights.
